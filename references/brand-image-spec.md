# 月明水清深品牌正文配图规范

## 品牌方向与宇航员模板

先读当前工程 AGENTS、已确认品牌规范与本期方向，接收上游已确认的封面及配图。发布器不另定人物身份或重新生成图片。其他已确认人物风格、真人封面与证据图不因本文件的旧模板被替换。

实际选用“月明宇航员”时，身份是圆润白色宇航服、黑色面罩与科技绿 C 形／月牙标志；按当前激活配图 Skill 的身份及风格参考核验。模板使用暖白、深墨蓝与铜橙（见 moonlit-content-engine brand-tokens；绿色 C 只作为宇航员 IP 识别保留），场景和道具服务主题。配图生成归独立配图 Skill，不假定当前文章 Skill 目录中一定有同名参考图。

## 正文图的内容职责

- 未另定方向的宇航员长文模板检查 2 张 `brand-ai` 场景图。已确认其他人物风格、纯证据图或其他数量时，在发布包保留方向依据；非宇航员解释图按 `explanation` 等实际类型登记，检查器和发布器传入同一个最低数量，可以为 0。不得虚标 IP 标志，也不得用 0 掩盖未登记、缺失或未确认的图片。封面、产品截图和装饰图不计入品牌图数量。
- 每张场景图必须解释相邻段落中的一个概念，例如痛点、机制、边界或结果，不能只做气氛装饰。
- 产品截图承担“证据”，解释场景图承担“理解与记忆”。顺序沿用正文论证和已确认安排，不为了模板机械交替。
- 优先使用动作表达关系：搬运、筛选、连接、进入隔离舱、保留身份核心。少用抽象光球和无意义粒子。
- 正文场景图使用横向构图，推荐 16:9；主体和关键动作在移动端缩小后仍可辨认。
- 图内默认不生成文字、Logo、界面小字或水印，准确文字由正文和图注承担。

## 配图清单

文章目录下创建 `assets/visual-manifest.json`，登记文章实际使用的全部图片：

```json
{
  "schema_version": 1,
  "brand": "月明水清深",
  "images": [
    {
      "path": "assets/5-伙伴筛选相关记忆.png",
      "type": "brand-ai",
      "meaning": "解释伙伴只带当前任务需要的记忆进入工作区",
      "ip_markers": ["moonlit-astronaut", "green-crescent-visor"]
    },
    {
      "path": "assets/4-独立会话工作区.png",
      "type": "product-screenshot",
      "meaning": "证明每个会话拥有独立工作区"
    }
  ]
}
```

发布前运行 `scripts/check_visuals.py`。只有 `type: brand-ai` 且同时包含两个固定 IP 标记的正文图才计入最低数量。

线稿沿用当前激活 moonlit-astronaut-illustration 的身份与风格参考；发布器不负责生成图片，不将写实材质、绿色灯带或某一张参考图强制套到已确认线稿。
